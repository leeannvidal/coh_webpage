Source code for the Communications On Hold company website.

## About

This repository contains the website for Communications On Hold, a woman-owned business providing professional on-hold messaging, voice production, and customer communication solutions since 1995.

The website shares information about the company, its services, and its commitment to personal service and professional results.

## Built With

This site was built using the [Hugo Blox](https://hugoblox.com/) website framework and customized using Hugo Blox templates and components.

The source code is hosted on GitHub and the site is deployed via [Netlify](https://www.netlify.com/).

If you’re interested in building your own website with Hugo Blox, visit their website to learn more and explore their templates and documentation.
